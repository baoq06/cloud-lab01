What is Cloud Computing?

According to the widely recognized NIST definition, cloud computing is an innovative service delivery model that provides convenient, on-demand network access to a shared pool of configurable computing resources—such as virtual servers, storage volumes, software applications, and network services—that can be rapidly provisioned and released with minimal management effort or service provider interaction.

Unlike traditional on-premises IT infrastructure where organizations must purchase physical hardware in advance, forecast capacity years ahead, and bear high capital expenditures (CapEx), cloud computing operates on an operational expenditure (OpEx) pay-as-you-go financial model. It provides five foundational characteristics: on-demand self-service, broad network access across laptops, smartphones and desktops, dynamic multi-tenant resource pooling, rapid elasticity to scale workloads automatically, and transparent measured service. By migrating to the cloud, businesses gain high availability, fault tolerance, and global reach without the heavy overhead of maintaining physical server rooms.

Cloud Service Models

Cloud computing capabilities are classified into three primary service models, differing in their level of abstraction, customer control, and operational responsibility:

IaaS

Infrastructure as a Service

Provides fundamental virtualized computing resources on demand, including virtual machines, block storage, and software-defined networking. The cloud provider operates the underlying physical hardware, while the customer maintains the operating system, middleware, and applications.

Concrete Example: Amazon EC2 (Elastic Compute Cloud)

Allows developers to provision virtual server instances in minutes with custom CPU, RAM, and OS choices.

PaaS

Platform as a Service

Provides a fully managed hardware and software execution environment for developers to build, deploy, run, and scale applications. Developers focus purely on application code and business logic, while the provider coordinates provisioning, patching, OS maintenance, and scaling.

Concrete Example: AWS Elastic Beanstalk

Deploys and scales web applications automatically across underlying AWS resources without manual server configuration.

SaaS

Software as a Service

Delivers end-to-end applications completely managed and operated by the cloud service provider. End-users access the software directly through a standard web browser or mobile client without installing or managing any underlying infrastructure.

Concrete Example: Google Workspace & Microsoft 365

Cloud-hosted productivity suites offering email, document editing, and cloud drive storage directly via the browser.
